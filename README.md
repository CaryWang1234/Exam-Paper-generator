# 智能试卷生成系统

基于 AI 技术的专业级试卷生成工具，支持自定义配置、多格式导出和学生个性化练习推送。

## 功能特点



* **智能生成**：基于 DeepSeek API 分析资料内容，自动生成高质量试卷

* **多种格式**：支持导出为 DOCX、HTML、PDF 等多种格式

* **灵活配置**：可自定义试卷类型、难度、总分、时间限制和题目类型

* **学生门户**：提供个性化练习订阅服务，支持按年级、科目定制

* **邮件推送**：定时向订阅学生发送每日练习题

* **系统管理**：可配置邮件服务和 API 密钥等系统参数

## 使用指南

### 生成试卷



1. 在首页选择或输入资料（支持 TXT、MD、DOCX、PDF 格式）

2. 配置试卷参数：

* 选择试卷类型（小练、考试、模拟考等）

* 设置难度级别（简单、中等、困难、竞赛级）

* 填写总分和考试时间

* 配置题目类型及数量（可选）

* 添加自定义指令（可选）

1. 点击 "生成试卷" 按钮

2. 生成完成后可预览并选择导出格式

### 学生练习门户



1. 点击首页 "学生练习门户" 进入

2. 填写个人信息：姓名、邮箱、年级、科目

3. 设置学习信息：知识范围、学习目标、特殊要求

4. 配置练习参数：难度、每日题量、偏好发送时间

5. 点击 "订阅个性化练习" 完成订阅

6. 系统将在指定时间发送练习题到你的邮箱

### 系统配置



1. 点击首页 "系统配置" 进入管理页面

2. 配置邮件服务器：

* 填写邮件服务器地址和端口

* 输入邮箱用户名和密码 / 应用密码

* 设置发件人邮箱

1. 配置 API：输入 DeepSeek API 密钥

2. 设置每日练习发送时间

3. 点击 "保存配置" 完成设置

## 技术栈



* 后端：Flask

* AI 接口：DeepSeek API

* 文档处理：python-docx

* 邮件服务：Flask-Mail

* 任务调度：APScheduler

* 前端：HTML、CSS、JavaScript

## 注意事项



* 需从 DeepSeek 官网获取 API 密钥：[https://platform.deepseek.com/](https://platform.deepseek.com/)

* 邮件服务器配置需开启 SMTP 服务：


  * Gmail 用户需开启两步验证并使用应用专用密码

  * QQ 邮箱 / 163 邮箱需开启 SMTP 服务并使用授权码

* 保存配置后可能需要重启应用才能生效
